# Kalendar

Проект управляется Роем (Nova + агенты). Стандартная инфраструктура.

## Структура
- `src/` — исходный код
- `tests/` — тесты
- `docs/` — документация
- `context/` — контекст проекта (паспорт, задачи, решения)
- `CLAUDE.md` — правила для агентов

## Начало работы

1. `git clone https://github.com/BishukRoma/Kalendar.git`
2. Заполнить `context/project.md` (тип, стек, аудитория)
3. Начать разработку

---

**Управление:** Nova 🌌 и рой агентов
