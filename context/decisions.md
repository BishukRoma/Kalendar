- **Причина:** Стандартная инфраструктура для всех проектов

## Мобильная версия: PWA, не нативное приложение
- **Решение:** PWA (Service Worker + Workbox + IndexedDB + Background Sync) поверх Next.js 14
- **Дата:** 2026-07-02
- **Инициатор:** пользователь
- **Причина:** ЦА работает со смартфонов, часто нет мобильного интернета в РФ → нужен офлайн-режим (просмотр броней + создание в очередь при отсутствии сети)
- **Отвергнуто:** React Native / Flutter — отдельная кодовая база, магазины приложений, ×3 к стоимости разработки. Пост-MVP если появится спрос и бюджет.
- **Ограничения офлайн:** синхронизация с площадками, оплаты и фискальные операции — только онлайн
