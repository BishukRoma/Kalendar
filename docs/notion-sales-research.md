## 1. Портрет целевого клиента RC

**Основной сегмент:** Собственники и управляющие с 10+ объектами посуточной аренды.

**Цель:** Максимизировать загруженность объектов при минимальных операционных затратах.

**Боли:**
- Ручное ведение броней в таблицах / разных площадках
- Риск овербукинга при работе с несколькими каналами
- Нет единого учёта расходов и реальной прибыли
- Сложная коммуникация с горничными и гостями

## 4. Регламенты CRM

### Статусы сделок в AMO CRM
Воронка продаж RC:
1. **Новый лид** — входящий запрос (сайт, реклама, реферал)
2. **Квалификация** — проверка соответствия ЦА (кол-во объектов, тип)
3. **Демо/Презентация** — показ продукта
4. **Коммерческое предложение** — отправка КП
5. **Согласование** — переговоры об условиях
6. **Оплата** — выставление счёта
7. **Внедрение** — онбординг и настройка
8. **Успешно закрыто** / **Отказ**

### Регламент менеджера
- Ежедневный разбор новых лидов
- Контакт с лидом в течение 15 минут после заявки
- Ведение всей коммуникации в CRM (звонки, письма, встречи)
- Еженедельный отчёт по воронке

### Расписание рабочего дня менеджера
- 9:00 — разбор задач и CRM
- 9:30–13:00 — исходящие звонки (квалификация + дожим)
- 13:00–14:00 — обед
- 14:00–17:00 — демо, встречи, КП
- 17:00–18:00 — фиксация результатов в CRM

## 6. Телефонные скрипты квалификации

### Скрипт 1 — Квалификация (входящий лид)
```
Цель: определить соответствие ЦА

1. Приветствие + представление
2. Подтверждение интереса: "Вы оставляли заявку на сайте RC?"
3. Квалификация:
   - "Сколько объектов у вас сейчас?"
   - "Как вы сейчас управляете бронированиями?"
   - "Работаете ли с площадками (Авито, Островок, Airbnb)?"
   - "Какая главная боль в текущем процессе?"
4. Если >5 объектов + площадки → предложить демо
5. Фиксация в CRM + следующий шаг
```

### Скрипт 2 — Квалификация (холодный звонок)
```
Цель: установить контакт, выявить потребность

1. Приветствие: "Добрый день, меня зовут [имя], RealtyCalendar"
2. Крюк: "Мы помогаем арендодателям избегать овербукинга и считать
   реальную прибыль с каждого объекта"
3. Вопрос: "Актуально ли для вас управление несколькими объектами сразу?"
4. Если да → квалификация (кол-во объектов, площадки, боли)
5. Если нет → "Когда лучше перезвонить?"
```

### Скрипт 3 — Квалификация (реферал / партнёр)
```
Цель: быстрое доверие через общего знакомого

1. "Здравствуйте, мне вас порекомендовал [имя партнёра] из [компании]"
2. Уточнение контекста: "Он сказал, вы работаете с посуточной арендой?"
3. Быстрая квалификация (кол-во объектов, текущий инструмент)
4. Сразу предложить демо (доверие уже есть)
```

### Дерево переговоров (возражения)
```
"Дорого" → 
  → Сравнение с потерями от овербукинга
  → ROI: 1 предотвращённый овербукинг = цена подписки
  → Рассрочка / поэтапное внедрение

"Уже есть система" → 
  → "Что именно используете?"
  → Выявить боли текущей системы
  → Покажи что умеем то чего нет у них (расходы, реальная прибыль)

"Нет времени разбираться" →
  → Онбординг под ключ (Расширенный пакет)
  → "Мы всё настраиваем сами, вам только одобрить"

"Пришлите материалы" →
  → Отправить + назначить follow-up через 2 дня
  → Не ждать — позвонить через 2 дня в назначенное время
```

## 7. Инсайты для нашего продукта

### Что взять из Sales-стратегии RC
- **Сегмент 10+ объектов** — именно здесь боль максимальна и готовность платить есть
- **Овербукинг как крюк** — главный страх арендодателя, наше главное УТП
- **ROI-продажи** — 1 предотвращённый овербукинг = окупает подписку
- **Онбординг под ключ** — снижает барьер входа для неопытных пользователей

### Что делать лучше RC
- **Self-service онбординг** — RC делает всё руками (дорого), мы строим guided setup
- **Аналитика реальной прибыли** — RC не умеет, это наш главный дифференциатор в продажах
- **Прозрачный расчёт ROI** прямо в интерфейсе (показать сколько сэкономили)

### Ценовые ориентиры рынка
- RC расширенный: ~11 000 руб./мес за пакет до 30 объектов + CRM
- Lodgify: ~60€/объект/мес (дорого для РФ рынка)
- Наш целевой диапазон: 3 000–8 000 руб./мес за 10–30 объектов
