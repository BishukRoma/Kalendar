## Что такое RealtyCalendar

SaaS-платформа для управляющих компаний и частных арендодателей посуточной аренды.
Основная ценность — единое окно управления несколькими объектами и каналами бронирования.

---

## Ключевые модули (из базы знаний)

### 1. Шахматка (Calendar Grid)
- Визуальная сетка: объекты по строкам, даты по столбцам
- Брони отображаются как цветные блоки с именем гостя
- Создание/редактирование брони прямо из шахматки
- Фильтры по объектам, статусам, источнику бронирования
- Перетаскивание броней (drag & drop)
- Подсветка конфликтов и свободных дат

### 2. Объекты недвижимости
- Карточка объекта: адрес, фото, описание, количество комнат, спальных мест
- Группировка объектов (по владельцам, зонам, типам)
- Статусы объекта: активен, на техобслуживании, скрыт
- Базовые и сезонные цены
- Минимальный срок аренды, правила заезда/выезда

### 3. Тарифы и цены
- Базовая цена за ночь
- Сезонные тарифы (диапазоны дат с отдельными ценами)
- Цена уборки и дополнительных услуг
- Скидки за длительное проживание
- Специальные цены на праздники

### 4. Управление бронями
- Источники: прямые брони, площадки (Airbnb, Booking, Ostrovok, Avito, CIAN)
- Статусы: запрос → подтверждена → активна → завершена → отменена
- Карточка брони: гость, даты, стоимость, предоплата, заметки
- История изменений бронирования
- Автоматические уведомления гостю

### 5. Мультиканальная синхронизация (Channel Manager)
- iCal экспорт/импорт (универсальный протокол)
- Прямые API интеграции с площадками
- Синхронизация цен и доступности в реальном времени
- Логи синхронизации
- **Ключевой механизм защиты от овербукинга**: при получении брони с любого канала немедленно блокировать даты на всех остальных

### 6. Клиенты (гости)
- База гостей с историей проживания
- Профиль гостя: контакты, документы, предпочтения, рейтинг
- Черный список
- Повторные гости

### 7. Финансы / Биллинг
- Приём платежей (наличные, карта, эквайринг)
- Счета и акты
- Баланс по каждому объекту
- Реестр платежей
- Долги и переплаты гостей

### 8. Аналитика и статистика
- Загруженность объектов (occupancy rate) за период
- Выручка по объектам и периодам
- Средняя стоимость ночи (ADR)
- Источники бронирований (по каналам)
- Отчёты для собственников

### 9. Интеграции
- AmoCRM, Bitrix24 (лиды из заявок)
- Телеграм-бот уведомлений
- Модуль онлайн-бронирования (виджет на сайт)
- Email-уведомления

### 10. Партнёрская программа
- Реферальная система
- Выплаты партнёрам

## Технические особенности RealtyCalendar

- Web-приложение (SaaS, subscriptions)
- iCal как основной протокол синхронизации
- Polling-based обновления (не event-driven)
- Монолитная или слабомодульная архитектура (судя по скорости разработки фич)

## Площадки интеграции (приоритет для MVP)

| Площадка | Протокол | Приоритет | Сложность |
|---|---|---|---|
| Airbnb | API + iCal | P1 | Средняя (API закрыт для новых партнёров, iCal — ок) |
| Ostrovok | API | P1 | Высокая (нужен договор) |
| Avito | API | P1 | Средняя |
| CIAN | API | P2 | Высокая |
| Яндекс Путешествия | API | P2 | Высокая (нужен договор) |
| Booking.com | XML/API | P3 | Высокая |

**Стратегия MVP**: начать с iCal для всех + прямой API там где доступен.
iCal — polling каждые 15-30 минут. Для критичной защиты от овербукинга нужен
механизм блокировки быстрее polling'а.
