## Страница 1 (март–июнь 2026)

### 30 июня 2026 — Редизайн раздела «Клиенты» (в разработке)
RC готовит новую версию раздела «Клиенты». Собирают фидбек через форму Яндекс.
Запрошенные функции: чёрный список гостей, сегменты клиентов, история проживаний, заметки.
**Инсайт:** у них этого ещё нет — мы можем сделать лучше с нуля.

### 29 июня 2026 — Модуль бронирования на 10 языках
Перевели интерфейс виджета для иностранных гостей. Язык по умолчанию выбирается в настройках, гость может переключить в шапке.
Следующий этап: ИИ-перевод названий и описаний объектов + расширение оплаты для иностранцев.

### 22 июня 2026 — Расширенная выгрузка броней в Excel
Новые поля в отчёте: дата создания, статус + дата обновления, источник, объект/адрес, даты/время заезда-выезда, гость+телефон, примечания, сумма, комиссия площадки, сумма оплаты, сумма возвратов, менеджер.
Путь: Отчёты → Отчёты → Выгрузка. По умолчанию — только главный пользователь.

### 29 мая 2026 — Новые отчёты управляющего
- **Pick-up отчёт** — динамика продаж: сколько броней было на дату A и стало на дату B по каждому дню выбранного месяца заезда. Для revenue management.
- **Окно бронирования** — за сколько дней до заезда бронируют (день в день / неделя / месяц).
- **Отмены по источникам** — % отмен и среднее окно аннуляции по каждому каналу.
- **Отмены по окнам** — за сколько дней до заезда чаще отменяют.
- **Выгрузка в Excel** — расширенный формат.

### 28 мая 2026 — ОкиДоки: разные шаблоны договоров на объект
Можно выбрать разный шаблон цифрового договора для каждого объекта (важно при разных условиях аренды).
Флоу: Настройки → Интеграции → бронь → «Создать договор» → ссылка → гость подписывает сам (паспорт, селфи, телефон).

### 20 мая 2026 — Автопилот: пакет обновлений
- Поиск брони по телефону в мобильном приложении
- Интеграция Автопилот + Автосообщения (ссылка на гостевую страницу в шаблонах)
- IP-телефония внутри Автопилота: история звонков, фильтр по броням/отменам, прослушивание
- **Автоматическое занесение постоянных расходов** — сумма, объекты, день месяца → Автопилот списывает сам (разделить поровну или фиксированная сумма на каждый объект)
- Раздел «Обслуживание» — задачи по объектам (что купить/починить), фильтр, копирование списка
- Сбор показаний счётчиков (вода, электричество, газ) горничными через приложение
- Вкладка «Переписка» в приложении горничных — история уборки в формате чата

### 14 мая 2026 — Монета для ЮЛ: доработки
- Галочка «Не создавать задолженность» при возврате (для скидок/компенсаций)
- Авто-повторная отправка чека «Полный расчёт» при ошибке кассы
- Чек «Полный расчёт» виден в брони при любой оплате через Монету/площадку
- Исправлен баг с возвратами (нехватка средств на счёте Монеты)
- Исправлено ручное редактирование суммы чека

### 13 мая 2026 — Страница бронирования (бета)
Гостю отправляется одна ссылка-ваучер: оплата, залог, маршрут, заселение, правила, контакты, договор, доп. услуги.
Брендированная, настраивается под объект. Открывается без авторизации, уникальная для каждой брони.
Каналы отправки: WhatsApp, MAX, email, Telegram-бот, SMS.
SMS теперь может вести на страницу (не только как резерв).

### 30 апреля 2026 — Чат в MAX прямо из бронирования
Переписка с гостем без выхода из карточки брони. Входит в автосообщения, без доплаты.

### 31 марта 2026 — Ссылка на оплату в автосообщениях
Тег `{{LINK_DEBT}}` в шаблоне → гость получает ссылку с суммой задолженности и оплачивает сам. Чек пробивается автоматически (при подключённом эквайринге).

## Ключевые инсайты для нашего продукта

### Что RC только строит — у нас должно быть с нуля
- **Омниканальный чат** — в разработке у RC с конца 2025, ещё не вышел. Мы можем заложить сразу.
- **Раздел «Клиенты» 2.0** — RC только собирает требования (июнь 2026). Чёрный список, сегменты, история.
- **Мультиязычность** — RC только начал (июнь 2026). Нам актуально если будем выходить за РФ.

### Автопилот = отдельный продукт RC (POST-MVP для нас)
Автопилот у RC — платная надстройка с: гостевой страницей, постоянными расходами, уборками, обслуживанием, телефонией, счётчиками. У нас это можно заложить в базовый продукт или сделать отдельным модулем.

### Постоянные расходы — RC только добавил в Автопилоте (май 2026)
Автоматическое занесение постоянных расходов появилось у RC в мае 2026 и только в платном Автопилоте. **Это наше ключевое конкурентное преимущество — заложить в базовый биллинг.**

### Автосообщения — активно развиваемое направление
RC вложил много в автосообщения (WhatsApp, MAX, Telegram, SMS, ссылка на оплату, ваучер гостя). Нам нужен аналогичный модуль уведомлений с поддержкой нескольких каналов.

### История гостя — важная фича (декабрь 2025)
Автопоиск гостя по телефону + история проживаний + список нежелательных гостей. Нужно заложить с нуля правильно.

### Цифровые договоры — партнёрская интеграция (ОкиДоки)
RC интегрировал ОкиДоки для онлайн-подписания. Для нас POST-MVP, но стоит предусмотреть в архитектуре (webhook-based интеграция).

### Pick-up отчёт + окно бронирования — продвинутая аналитика
RC выпустил в мае 2026. Это revenue management инструменты для крупных агентств. Хорошо вписывается в наш Block 8 (аналитика).

### Канал MAX (VK) — российская альтернатива WhatsApp
RC добавил после угроз блокировки WhatsApp. Для нашего модуля уведомлений — учесть как один из каналов.
